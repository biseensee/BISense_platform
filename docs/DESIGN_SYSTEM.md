# Дизайн-система платформы — Sber Style

Источник вдохновения: публичный визуальный стиль сайта СберБизнес
(`sberbank.ru/ru/s_m_business`) и официальная айдентика бренда «Сбер» (ребрендинг 2020).
Прямой парсинг страницы недоступен (`robots.txt` блокирует автоматическую выгрузку),
поэтому цвета и типографика взяты из официальных источников бренда и брендбуков-гайдлайнов
(см. раздел «Источники» внизу файла) и адаптированы под расчётную, CVD-безопасную
палитру графиков по методике `dataviz`-скилла.

> Прикладной шрифт Сбербанка «SB Sans Text/Display» — проприетарный (распространяется
> только по запросу через `sberid@sber.ru`), поэтому в качестве легального веб-шрифта
> используется **Golos Text** — открытый (OFL) шрифт, изначально разработанный
> дизайн-командой SberDevices для экосистемы Sber (голосовые ассистенты «Салют» и др.),
> опубликован в Google Fonts. Визуально он максимально близок к фирменному начертанию
> и безопасен для production-использования.

## 1. Бренд-токены (UI-хром, не для графиков напрямую)

| Токен | HEX | Назначение |
|---|---|---|
| `--brand-green` | `#21A038` | Основной бренд-цвет («SberGreen»): primary-кнопки, активные состояния, логотип |
| `--brand-green-dark` | `#168029` | Hover/active состояние primary-кнопки |
| `--brand-blue` | `#0098F8` | Акцент градиента, ссылки, info-состояния |
| `--brand-yellow` | `#F1E813` | Акцент градиента (декоративно, не для текста — низкий контраст) |
| `--brand-black` | `#000000` | Логотип, крайние состояния текста |
| `--brand-white` | `#FFFFFF` | Базовый фон карточек |

Фирменный градиент Сбера (`blue → green → yellow`) используется точечно: хиро-баннеры,
верхняя полоса навигации, decorative accent — никогда как заливка графика (нечитаемо и
не проходит CVD-проверку).

## 3. Типографика

- **Шрифт:** `"Golos Text", system-ui, -apple-system, "Segoe UI", sans-serif`
- Числовые KPI/hero-цифры: те же пропорциональные цифры (никакого `tabular-nums`,
  кроме колонок таблиц и подписей осей — правило `dataviz`-скилла).
- Масштаб: `H1 32/40 700`, `H2 24/32 700`, `H3 18/24 600`, `Body 15/22 400`,
  `Caption 13/18 500`, `KPI-value 40/44 700`.

## 4. Палитра графиков (расчётная, прошла `validate_palette.js`)

Категориальная последовательность — порядок из брендбука `dataviz`-скилла
(`references/palette.md`), с заменой слота «green» на фирменный `#21A038`,
**повторно провалидирован** скриптом `validate_palette.js` — все проверки
(lightness band, chroma floor, CVD-разделение, normal-vision floor, контраст) пройдены
(см. лог ниже). Порядок слотов фиксирован — никогда не переставлять и не «прокручивать»
дополнительные оттенки.

| Slot | Роль | Light | Dark |
|---|---|---|---|
| 1 | blue | `#2a78d6` | `#3987e5` |
| 2 | orange | `#eb6834` | `#d95926` |
| 3 | aqua | `#1baf7a` | `#199e70` |
| 4 | yellow | `#eda100` | `#c98500` |
| 5 | magenta | `#e87ba4` | `#d55181` |
| 6 | **Sber green (brand)** | `#21A038` | `#21A038` |
| 7 | violet | `#4a3aa7` | `#9085e9` |
| 8 | red | `#e34948` | `#e66767` |

Результат валидации (light): `PASS` lightness band, `PASS` chroma floor, `PASS` CVD
separation (worst adjacent ΔE 9.1), `PASS` normal-vision floor (ΔE 19.6), `WARN`
contrast — три слота (`aqua`, `yellow`, `magenta`) ниже 3:1 к поверхности `#fcfcfb` →
обязательны видимые прямые подписи/легенда (relief rule), не полагаемся на заливку.
Dark: все проверки `PASS`, кроме `WARN` CVD adjacent `Sber green ↔ magenta` (ΔE 7.6,
зона 6–8) → та же relief-мера (подписи).

Слоты 1–3 дополнительно проходят all-pairs проверку — можно безопасно использовать для
scatter/bubble/choropleth без ограничения на смежность.

### Последовательная шкала (magnitude, heatmap/progress) — фирменный зелёный

| Step | 100 | 200 | 300 | 400 | 500 | 550 (brand) | 600 | 700 |
|---|---|---|---|---|---|---|---|---|
| Hex | `#dff6e3` | `#bfeec7` | `#99e6a7` | `#65dc7b` | `#2dd24b` | `#21A038` | `#18812c` | `#0f5c1d` |

Монотонная по светлоте (OKLCH), якорь — точный бренд-хекс на шаге 550. Для
heatmap/непрерывных шкал — весь диапазон; для ordinal (дискретные упорядоченные
уровни, напр. воронка) — не светлее шага 300 на светлой поверхности (правило
контраста 2:1).

### Диверирующая пара (полярность, напр. план/факт отклонение)

`blue #2a78d6 ↔ red #e34948`, нейтральный midpoint — `#f0efec` (light) / `#383835`
(dark). Взято без изменений из базовой палитры `dataviz`-скилла (валидированная пара,
Sber-специфичной диверирующей пары в брендбуке нет).

### Статусная палитра (фиксирована, никогда не используется как категориальная)

| Роль | Hex | Контраст (light) | Контраст (dark) |
|---|---|---|---|
| good | `#0ca30c` | 3.27 | 5.19 |
| warning | `#fab219` | 1.79 | 9.49 |
| serious | `#ec835a` | 2.57 | 6.60 |
| critical | `#d03b3b` | 4.68 | 3.62 |

`warning`/`serious` на светлом фоне — ниже 3:1: обязателен значок + подпись, никогда
только заливка.

### Текстурная заливка (accessibility fallback)

Одна штриховка «Lines» 45°/135°, включается только по настройке доступности, печати
или `forced-colors` — не декоративно.

## 5. Источники

- Официальная айдентика Сбера (градиент blue→green→yellow, `#0098F8`/`#21A038`/`#F1E813`):
  бренд-обзор логотипа Сбербанка.
- Руководство по интеграции Сбер ID (`developers.sber.ru/docs/ru/sberid/guidebook`) —
  типографика (SB Sans Text для web), правила кнопок/скруглений.
- Golos Text — открытый шрифт SberDevices, Google Fonts / Fontsource.
- Прямая выгрузка `sberbank.ru/ru/s_m_business?segment=you` заблокирована `robots.txt`
  для автоматических агентов — визуальные паттерны карточек (крупный радиус, мягкая
  тень, зелёный акцент на CTA) воспроизведены по общей узнаваемой стилистике бренда,
  а не путём прямого парсинга страницы.
